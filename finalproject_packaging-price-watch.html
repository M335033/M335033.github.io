An AI agent that tells procurement when a packaging contract price has to change.

Every morning a scheduled agent reads the internal packaging raw-material index, replays each supplier contract's review rules, and updates a shared dashboard: which prices go up or down, from when, and why.

Hidayah AhmadMDBM, Hochschule PforzheimProf. Dr. Pin Luarn · WiSe 2026/27Demo data: Oct 2026 index data, review cycle Nov 2026

The problem

Packaging supply contracts often contain a price adjustment clause tied to raw-material prices. Checking them by hand every month is slow and easy to get wrong.

Many contracts, different rules

Each contract has its own material mix (e.g. 60% paper, 40% plastic), base period, review frequency and trigger (e.g. ±5%).

Monthly data, moving baselines

Index values arrive early each month. After every adjustment the base period moves, so the comparison changes over time.

Missed reviews cost money

A missed price increase strains the supplier relationship; a missed decrease means overpaying. The team needs one shared view, every day.

How it works

The agent orchestrates the work; the arithmetic is done in tested code, because language models are strong at language but not always accurate with numbers.

How the review works
  • Each contract is reviewed in windows that start in its contract start month (a mid-month start counts from the 1st). Window length: quarterly 3 months, bi-annual 6, annual 12.
  • Change = sum over materials of share × (window average ÷ base average − 1), each material against its own base average.
  • If the change is at least the trigger, up or down (hitting it exactly counts), the price changes by the full change and that window becomes the new base period. Otherwise the base stays.
  • A window ending in month M is reviewed in M+1, once M's index is published, and a new price applies from the 1st of M+2.
  • Watch means the window still running is already at 80% of the trigger or more, based on the months published so far.
  • The calculation runs in code (review_engine.py) every day; the dashboard shows its results.
